# RealGM 选秀权数据抓取报告

## 数据来源
- **网站**: [RealGM - NBA Future Drafts By Team](https://basketball.realgm.com/nba/draft/future_drafts/team)
- **抓取日期**: 2026-06-08
- **存档来源**: Wayback Machine (archive.org)

## 解析方法
- **每个 `;` 分隔段 = 一个独立的选秀权**
- RealGM 表格每行末尾的数字（如 `2`、`1+1`、`3`）为该轮次该队总选秀权数
- `Own` = 球队保留自己的签位
- `To XXX` = 该签位送至另一支球队（不计入本队）
- `Frozen` = 该签位因前序交易被冻结
- `TEAM XX-XX` = 来自该球队的签位（XX-XX 为顺位范围）

## 顺位范围格式
- `#1-#4` = 第1到第4顺位
- `#15-#30` = 第15到第30顺位
- `#31-#55` = 第31到第55顺位
- 以此类推...

## 保护条款说明
| 保护代码 | 含义 | 解释 |
|---------|------|------|
| `top2` | 前2保护 | 若落在前2顺位则归原队 |
| `top3` | 前3保护 | 若落在前3顺位则归原队 |
| `top4` | 前4保护 | 若落在前4顺位则归原队 |
| `top5` | 前5保护 | 若落在前5顺位则归原队 |
| `top8` | 前8保护 | 若落在前8顺位则归原队 |
| `top14` | 乐透保护 | 若落在前14顺位（乐透区）则归原队 |
| `top16` | 前16保护 | 若落在前16顺位则归原队 |
| `top20` | 前20保护 | 若落在前20顺位则归原队 |

## 已知限制
1. RealGM 的复杂多方交换（如篮网/太阳/76人2028年 N 方交换）无法被自动解析完全拆解为单队视角
2. 部分条件性保护（如"若X队未在Y年送出首轮"）在自动化解析中可能被简化为无条件
3. 涉及"最有利/最不利/次有利"等多队比较的复杂交换，解析器可能无法完全正确归属
4. 建议对于篮网、奇才、雷霆等涉及大量复杂交换的球队，可手动微调具体条目

## 使用方式
在 `NBA AI经理 · 交易模拟器.html` 中，该文件在 `player-options.js` 之后被加载：
```html
<script src="./NBA AI经理 · 交易模拟器_files/js/draft-picks.js"></script>
```
定义全局变量 `DRAFT_PICKS_DATA`，覆盖 `data.js` 中的旧数据。
