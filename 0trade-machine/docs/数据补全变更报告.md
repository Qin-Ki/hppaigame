## 三、数据质量说明

### ✅ 精准数据（来自 Basketball-Reference）
- **球员薪资** — 与 Basketball-Reference 2025-26 赛季合同数据完全一致
- **球员身份** — 英文名 + 中文译名，确保对应关系正确
- **球队归属** — 按 BBR 球队花名册精确分配

### ⚠️ 估算数据（程序生成）
以下字段因无法从合同页获取，采用基于薪资等级的估算：

| 字段 | 估算方法 |
|------|---------|
| **per** (效率值) | 按薪资分档：>$30M→18, >$15M→14, >$7M→11, >$2M→9, 其他→8 |
| **pos** (位置) | 按薪资分配：高薪→F, 中薪→G, 低薪→G |
| **ht** (身高) | $30M→79英寸, $15M→78英寸, 其他→77英寸 |
| **wt** (体重) | $30M→215lbs, $15M→210lbs, 其他→200lbs |
| **exp** (经验) | $30M→'8', $15M→'6', $7M→'4', 其他→'2' |
| **stats** (数据) | 按四档薪资生成模板化的场均数据 |
| **yearsRemaining** | 统一为 2 年 |

## 四、使用说明

### 如何应用这批数据
1. 打开 `data_patch_output.txt`
2. 找到对应球队的 `players` 数组
3. 将新条目按编号顺序插入到数组末尾
4. 注意每个条目末尾有逗号 `,`

### 示例：为篮网插入新球员
```js
players: [
  // ... 原有球员 ...
  { id:'bkn-clownenoa-21', name:'诺厄-克洛尼', salary:3398640, ... },
  { id:'bkn-wolfdan-22', name:'丹尼-沃尔夫', salary:2801280, ... },
  // ... 更多 ...
]
```
