# 🏀 Immaculate Grid Basketball

A mobile-responsive NBA trivia game in a **single HTML file**. No server needed — just double-click and play.

Fill a 3×3 grid with NBA players who match both row and column categories.

## Features

- **Daily Grid** + **Random Grid** — unlimited play
- **3×3 Grid** — rows and columns are NBA teams, stats, or awards
- **Player Search** — autocomplete with NBA player names and headshots
- **Answer Validation** — checks if a player satisfies both criteria
- **Rarity Scoring** — tracks pick frequency in localStorage
- **Mobile-First** — responsive design optimized for phones
- **Share** — copy results as emoji grid text
- **No server, no login** — just a single HTML file

## Quick Start

```bash
# Option 1: Just play (no build needed)
double-click public/index.html

# Option 2: Rebuild data from NBA API (requires Node.js)
npm install
npm run build
open public/index.html
```

## How to Play

1. Click any empty cell in the 3×3 grid
2. Type an NBA player's name and select from autocomplete
3. The player must match **both** the row and column category
4. You get 9 guesses total (one per cell)
5. Lower rarity % = more obscure pick = better score!

## Project Structure

```
immaculate_grid/
├── public/
│   └── index.html      ← Self-contained game (98KB), just open it
├── scripts/
│   └── buildOfflinePlayers.js  ← Build script (fetches NBA data)
├── build-cache/        ← Cached player data (generated by build)
└── package.json
```

## Data

- **Built-in**: ~550 players with full validation data (all-stars, current players, key role players)
- **More players can be added**: Edit `scripts/buildOfflinePlayers.js`, run `npm run build`
- Player headshots and team logos load from NBA CDN

## Tech

- 100% client-side HTML + CSS + JavaScript
- No frameworks, no build tools for the game itself
- Build script uses `nba-api-client` to pre-compute validation data
